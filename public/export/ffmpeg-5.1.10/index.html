Plexus MP4 export: source and notices

Plexus uses FFmpeg 5.1.10, licensed under LGPL 2.1 or later, in a separate Web Worker for AAC encoding and MP4 muxing. The core contains no libx264. You can rebuild and replace the core files below. The browser supplies H.264 or 10-bit VP9. FFmpeg reads VP9 stream properties while remuxing its original packets.

  • FFmpeg LGPL license and exact FFmpeg source
  • FFmpeg WASM binding license and exact binding source
  • build instructions, JavaScript module and WASM module
  • Mediabunny MPL 2.0 license and Mediabunny 1.39.1 source package (includes src/)

Rebuild from this directory with Docker:

docker buildx build -f ffmpeg-mp4-core.Dockerfile --output type=local,dest=rebuilt .

In a local build or deployment of Plexus, replace the two ffmpeg-core files in this directory with the rebuilt files, then reload the app. The worker uses the module interface from the supplied binding source.
