# AN-04D frozen prefix forecast protocol

Owner: analyzer DSP/types and retained research/test harness; no playback, worker, state, visual or XR integration.

Freeze before measurement. Original-clock prefix N=next power of two >=80ms, hop=round(20ms), immediate withheld suffix N/2. Only complete windows, no padding, resampling, teacher F0, isolation or labels. Caller hashes each prefix separately. AN-04B periodicity runs on that prefix alone. Both fixed models are always reported: DC plus <=8 harmonic cos/sin terms, and DC plus linear-in-time cos/sin coefficients, u=i/(N-1)-0.5. Two-pass modified Gram-Schmidt with relative column rank tolerance 1e-10, all training products prefix-only. No future score selects a model. Suffix energy uses prefix mean; below-floor suffix gives null; ratios unbounded.

New development tuples: Fs16000, F220.3, phase0.37. Frozen transfer: Fs22050, F273.41, phase1.31. Eleven 480ms authored controls include stationary, linear rise/fall, quadratic envelope, gain step, vibrato, chirp, octave/unison/incommensurate mixtures, silence. Truth stays evaluator-only. Replay all AN-04B baseline synthetic cases and three retained AN-04B 10-12s original-clock recorded excerpts. Geometry differs from AN-04C: its full-frame F0 conditional residual is not a predictive baseline.

Arithmetic: actual pinned NumPy/SciPy least squares on deterministic first/last available frame of each case, both fixed models. Retain ranks, scores, raw output, versions, source/native hashes; absolute score agreement <=1e-10 and same rank is arithmetic verification only. Gram-Schmidt rank heuristic is not claimed equivalent to global SVD cutoff.

Pitch: actual pinned librosa YIN/audioFlux NCF, separately isolated prefix PCM on the same deterministic first/last *complete* frame per case, including no-pitch/silence controls. Accept reference only when both original votes agree <=25 cents; own candidate must be within25 cents of BOTH. Raw disagreement/absence preserved. No vote fallback, no confidence or ground truth, no claim about unmeasured frames. Agreement cannot validate a forecast, physical source, motif or XR scoring. Sampled arithmetic and sampled pitch coverage are separate.

Report scores by case, retained failures and runtime, all old tests plus new tests, immutable source snapshots and cumulative inventory/history. No thresholds tuned on transfer or recorded music; no production promotion. Expected falsification: smooth linear envelopes may improve; abrupt onset/gain change and frequency modulation can remain unpredictable; octave/unison mixtures may fit despite multiple authored sources.
